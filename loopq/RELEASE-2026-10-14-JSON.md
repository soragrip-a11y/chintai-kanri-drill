# JSON取込改善プレビュー — 2026-10-14

対象は /loopq の手動取込のみ。旧トップページ、DB名・バージョン、ストア、設定キー、バックアップ形式は変更しない。

## 診断と変更

旧処理は前後文付きJSONとJSON文字列に包まれた回答で失敗する。利用者が実際にコピーした文字列は入手できず、今回の実入力の原因は未確定。参照チャットの回答本文も参照用マーカーのみで取得不可。

通常JSON、単一オブジェクトの前後文・コードフェンス、最大2層の正規JSON文字列、旧版対応の文字列外Markdown括弧エスケープを扱う。文字列内容、正答、法令や出典は推測で変更しない。smart quotesの構文、裸のバックスラッシュ付き引用符、DIL等の不明な表記は拒否し再コピーを案内。重複キー、複数候補、途中切れ、型、項目、件数、文字数、深さを検査する。

保存前にtextContentによる全文プレビューを必須とし、編集後は確認を無効化。既存類題・学習履歴は上書きしない。保存成功前に元レコードを変更しない。DB変更・移行なし。SWキャッシュ更新はLoopQ接頭辞に限定し旧トップページのキャッシュに触れない。

データフロー：クリップボード → 端末内テキスト欄 → 制限付き解析 → 端末内プレビュー → 利用者確認 → IndexedDB。同処理による外部送信・生成・法令検証はない。
