# LoopQ テスト版（ベータ）

資格を問わず、間違えた問題の写真と自作・ChatGPTで作成した問題を端末内に蓄積するWebアプリ。

## いまできること
- 写真／メモの端末内保存（IndexedDB）。写真は自動送信されません。
- 自身のChatGPT向け作問指示を生成してコピー。ChatGPT側で本人が写真を添付・送信。
- ChatGPTが返したJSON形式の3問を本人が確認し、端末内に取り込む（自動連携ではありません）。
- ○×形式の復習、苦手マーク、履歴保存、バックアップと復元。
- PWA / モバイル対応。非公式・広告／登録／運営者のAI API呼出しなし。

## 実施した検証（2026-10-14）
- `node --check`：app.js と safety.js 構文エラーなし
- バックアップ／データ検証のセキュリティテスト9件に合格
- Playwright / Chromium の **模擬ストレージ環境**：
  - 画像選択→保存→ChatGPT用指示文→3問JSON取込→3問復習
  - JSONバックアップ→全削除→復元、390px画面の横はみ出し検査：成功
- ブラウザーのHTTP URLへのナビゲーションは実行環境の管理者制限により遮断。iPhone Safari + 実IndexedDBの検証は未実施。

## 重要な制限
- ChatGPTアカウントとの自動連携、写真の自動解析・類題の直接生成は未実装です。
- AIが返した問題や解説は根拠法令で照合した保証がありません。実利用前に本人が確認してください。
- 保存データはブラウザのサイトデータを消去すると失われ得ます。大量画像保存にも限界があるためバックアップ必須。
- 問題集の写真を第三者へ再配布する機能はありません。ChatGPTへ送るときは本人が著作権・個人情報・利用規約を確認してください。

既存の賃貸管理士ドリル（ルートの index.html）は維持し、別の `loopq/` パスで公開しています。
