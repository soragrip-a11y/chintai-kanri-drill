# LoopQ — テーマから作問、JSONで学習（プレビュー版）

1. ホームの「問題を作る」で学びたいテーマを入力。問題数は通常10問、上下の矢印で10〜100問（10問刻み）。
2. 「指示文をコピーしてChatGPTを開く」を押し、ChatGPTに貼り付けて送信。
3. 回答のJSONをコピーし、「JSONを取り込む」に貼り付けて保存・学習。

LoopQは指示文を端末内で組み立てます。AI生成や自動送信は行わず、APIキーも不要です。ChatGPT側の利用条件・上限が適用されます。コピーや別タブが使えない場合は、表示した指示文を手動でコピーし、通常のリンクからChatGPTを開いてください。

学校・仕事・資格などのテーマに対応する指示文です。AIの正答・解説・出典は未検証です。法令等は適用年度・地域・基準日と一次資料を確認してください。写真からの自動作問は「開発中」の案内のみで、撮影・画像送信・API接続はできません。

## 保存と互換性

既存のIndexedDB `loopq-library-v2`、設定、問題、添付データ、学習履歴、途中の復習を維持します。今回のUI変更でデータの移行・消去・置換は行いません。以前の写真機能は公開画面から除去しましたが、保存済み添付データはバックアップに含まれます。`loopq.original.v1` の既存問題集は引き続き取り込めます。全体バックアップは設定から書き出してください。端末やブラウザー間で自動同期はしません。

JSONは最大1,000問。コードブロック対応、重複取り込み防止、全件検査・一括保存、正答不明の採点除外を維持しています。復習の続き・前の問題・右側の次の問題も維持しています。

## 検証

`node --test loopq/*.test.cjs`（リポジトリルート）。写真専用の旧UI試験は明示的にスキップし、パーサー・保存・進捗・JSON取り込みの回帰試験は維持します。

実ブラウザー試験: `python loopq/original-browser-smoke.py`（先にルートを127.0.0.1:8767で配信）。今回の環境ではChromium起動がsocket制限で失敗したため、ブラウザー表示・実機Safari・PWAの目視検証は未完了です。プレビュー版として公開します。
