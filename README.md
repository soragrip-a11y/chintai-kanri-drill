# 賃貸管理士ドリル（2026）

賃貸不動産経営管理士に向けた、非公式・非営利・無料の学習Webアプリ（PWA）。公式の過去問のコピーや軽微な改題ではなく、国土交通省の一次資料に基づくオリジナル問題50問を掲載しています。

## 使い方

静的Webサイトです。リポジトリのルートを GitHub Pages で公開（Deploy from a branch → `main` → `/ (root)`）。`index.html` を `file://` で開くと JSON 読み込みが失敗するため、ローカル確認は `python -m http.server 8000` を使ってください。

## 学習機能

* 分野別の4択演習、10問ランダム演習、50問・120分の模擬試験
* 正誤判定、解説と公的根拠リンク、復習、ブックマーク
* ローカルストレージの学習履歴、JSONでバックアップ／復元
* iPhone等のホーム画面追加・オフライン閲覧（初回読み込み後）

## 注意

* 試験実施団体や行政機関とは無関係の非公式サービスです。
* 2026年度試験の法令・関連告示等の基準日（2026年4月1日）を想定しています。
* 本番過去問の再現・頻出度の保証はしていません。公的資料へのリンクから最新の解釈を確認してください。
* 無償学習用。再利用や商用転用を行う際は出典と著作権の確認をしてください。

## ファイル

- `questions.json` 全50問の問題データ
- `build_questions.py` 出題データ生成・静的検証
- `app.js`, `style.css`, `index.html` UI
- `sw.js`, `manifest.webmanifest`, `icon-*` PWA
