# 賃貸管理士ドリル 2026

賃貸不動産経営管理士試験向けの、無料・非公式のオリジナル問題学習Webアプリ（PWA）です。

## 公開方法

リポジトリの **Settings → Pages → Build and deployment** で、`Deploy from a branch` を選び、`main` と `/(root)` を指定して Save を押します。

公開先（Pagesの設定完了後）: https://soragrip-a11y.github.io/chintai-kanri-drill/

## ファイル構成

- `index.html` — 問題データとJavaScript・CSSを埋め込んだ単独動作版
- `questions.json` — 50問のオリジナル問題データ（監査・更新用）
- `sw.js` — オフライン用Service Worker
- `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` — PWA用
- `PUBLISH.md` — 公開設定の手順

## 機能

分野別4択演習、10問ランダム演習、50問・120分の模擬試験、解説と公的資料へのリンク、誤答の復習、ブックマーク、学習履歴の端末内保存、バックアップ／復元。

## 問題の扱い

- 過去問の原文を転載するものではありません。根拠資料から独自に作問しています。
- 2026年度試験の基準日である **2026年4月1日** を基準としています。
- 問題・選択肢・解説は構造チェックおよび基本動作テストを実施しましたが、法令上の正確性について専門家による最終保証はありません。試験直前の確認には公式資料も参照してください。
- 試験実施団体や国土交通省とは無関係の非公式学習サイトです。

## 非商用

登録・課金・広告・トラッキングを設けない非商用プロジェクトです。学習履歴は利用者のブラウザ内に保存されます。
